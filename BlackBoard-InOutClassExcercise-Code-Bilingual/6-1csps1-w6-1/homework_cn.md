# 作业 — 同题程序实现：澳大利亚地图着色（CSP）

实现一个小型 CSP 工具并求解该地图：

1) **CSP 核心**  
   - `variables`、`domains` 与二元 `constraints`（谓词）。  
   - 提供 `neighbors(var)`。

2) **回溯搜索**  
   - 变量顺序：**MRV + 度数打平**；  
   - 取值顺序：最少约束值（LCV）；  
   - **前视检查**（Forward Checking），带撤销栈。

3) **日志与指标**  
   - 统计节点数、回溯次数；输出赋值顺序与每步前视后的域。

4) **实验**  
   - 比较：朴素回溯 / +MRV / +MRV+LCV / +MRV+LCV+FC；  
   - 在澳大利亚数据集上报告节点数；可选再做 **N 皇后（N=8）**。

5) **（选做）**  
   - 实现 **AC-3** 并与前视比较；  
   - 增加**排程**（表述一），解一个小实例。

**提交**：代码 + ≤2 页小报告（节点数表格与简要分析）。
