# 板书（中文）— 课程总结与路线图（范式 · 工具 · 伦理）

## 四类建模范式（场景适配）
- **反射式（低层信号→动作）**  
  *模型*：线性/神经网络/kNN；*推断*：前向；*学习*：SGD/交替最小化。适合感知与即刻决策。  
- **状态式**（用状态 \(s\) 概括过去）  
  *模型*：搜索、**MDP**、对弈；*推断*：UCS/A\*、DP/价值迭代、极小极大；*学习*：结构化 Perceptron、Q/TD。  
- **变量式**（因子图表达条件独立）  
  *模型*：**CSP**、马尔可夫网、贝叶斯网；*推断*：回溯/AC-3、前向–后向/束搜索、Gibbs/MCMC；*学习*：MLE/EM。  
- **逻辑式**（公式与可能无限模型）  
  *模型*：命题/一阶逻辑；*推断*：模型检测、**肯定前件**、归结；*学习*：仍在发展中。

## 机器学习即损失最小化
\(\min_w \sum_{(x,y)\in D_{\text{train}}}\!\mathrm{Loss}(x,y;w)\)，SGD：\(w\!\leftarrow\! w\!-\!\eta_t\nabla \mathrm{Loss}\)。

## 工具化思维
从**问题出发**选**最简单可用**的工具，避免过度设计。

## 伦理要点：data → models → predictions
- **数据**：网络抓取含攻击性与历史偏见；应重视同意与数据劳动。  
- **目标**：替代指标（如点击）易失配。  
- **不平等**：审计与最差组损失；权衡公平与性能。  
- **潜在危害**：双重用途（deepfake、自主武器）。  
- **IA vs AI**：更多关注**智能增强**而非替代。  
**结论**：能做≠该做；权衡收益/风险与情境。
