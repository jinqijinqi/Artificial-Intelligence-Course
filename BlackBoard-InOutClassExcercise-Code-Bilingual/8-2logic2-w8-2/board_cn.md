# 板书（中文）— 逻辑 II（Horn · 合取范式 · 归结 · 一阶逻辑 · 合一 · 一阶归结）

## Horn 与肯定前件（MP）
- **定式子**：\((p_1\land\cdots\land p_k)\to q\)。**Horn 子句**：定式子或**目标子句**\((p_1\land\cdots\land p_k)\to \bot\)。
- **MP 规则**：由 \(p_1,\dots,p_k,(p_1\land\cdots\land p_k)\to q\) 推出 \(q\)。
- **定理（Horn 上完备）**：KB 仅含 Horn 子句且命题 \(p\) 被蕴含，则用 MP 可推出 \(p\)。
- **权衡**：Horn+MP ⇒ 线性时间前向链；一般命题逻辑需更强规则。

## 命题归结（Resolution）
- 蕴含改写：\(A\to C \equiv \lnot A\lor C\)；**子句**为文字（命题或其否定）的析取。  
- **归结规则**：\((f_1\vee\cdots\vee f_n\vee p),(\lnot p\vee g_1\vee\cdots\vee g_m)\Rightarrow (f_1\vee\cdots\vee f_n\vee g_1\vee\cdots\vee g_m)\)。
- **CNF**：子句的合取。**反证法判蕴含**：KB ⊨ \(f\) 当且仅当 KB∪{¬\(f\)} 推出**空子句** \(\Box\)。

### 合取范式转换
去 ↔、→；向内推 ¬（德摩根）；消双重否定；**分配律**把 ∨ 分配到 ∧；（可先变量标准化）。

## 一阶逻辑基础
- **项**：常量、变元、函数；**原子式**：谓词作用于若干项；**量词**：∀、∃。  
- **代入**：Subst[\(\theta\), \(f\)]；**合一**：Unify[\(f,g\)] 给出最普遍替换 θ 使两式相同。  
- **一阶 MP**：先把前提与规则前件**合一**得 θ，再推 Subst[θ,\(b\)]。  
- **一阶 CNF**：去 →/↔、推 ¬、**Skolem 化**（∃ 替换为依赖 ∀ 的 Skolem 函数）、去 ∀、分配，得子句。  
- **一阶归结**：先合一互补文字，再对结论施加 θ。

## 复杂度
- Horn 上 MP：线性；归结（命题/一阶）：最坏指数；一阶逻辑**半可判定**（不蕴含时可能不停止）。
