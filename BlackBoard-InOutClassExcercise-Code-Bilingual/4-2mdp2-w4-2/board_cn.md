# 板书（中文）— MDPs 2（策略迭代 · Bellman 算子 · 收缩性 · Q 迭代）

**Bellman 算子**
- 策略算子： (T^π V)(s)=Σ_{s'} T(s,π(s),s')[R(s,π(s),s')+γV(s')]  （在无穷范数下 γ 收缩）
- 最优算子： (T^* V)(s)=max_a Σ_{s'} T(s,a,s')[R(s,a,s')+γV(s')]  （γ 收缩）

**误差界**
若 ||T^*V − V||_∞ ≤ ε ⇒ ||V − V^*||_∞ ≤ ε/(1−γ)。

**策略迭代**
评估（求 V^π）↔ 改进（对 V^π 贪心）；有限 MDP 有限步终止。

**Q 迭代**
Q_{t+1}(s,a)=Σ_{s'} T(s,a,s')[R(s,a,s')+γ max_{a'}Q_t(s',a')]；π(s)=argmax_a Q(s,a)。

**实践**
- 异步/就地 VI；优先级扫描。
- 用 Bellman 残差作停止；乐观初始化可加速。
